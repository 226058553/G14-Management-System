# G14 Hospital Management System

This repository contains the project documentation, presentation materials, cover image, and SQL scripts for the G14 Hospital Management System.

## Repository contents

- `Cover Page Image/Designer.png` — project cover image
- `PDF/G14 Hospital Management System.pdf` — project report
- `Powerpoint slides/G14 Hospital Management System.pptx` — project presentation
- `SQL Scripts/` — database definition, sample data, and SQL examples

The SQL files are provided as project materials; this repository does not currently include an application implementation.
